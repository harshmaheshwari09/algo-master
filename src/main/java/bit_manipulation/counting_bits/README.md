# Counting Bits

[AlgoMaster Problem](https://algomaster.io/practice/dsa/counting-bits?list=am-75)  
[LeetCode Problem](https://leetcode.com/problems/counting-bits/)

Given an integer `n`, return an array `ans` of length `n + 1` such that for each `i` where `0 <= i <= n`, `ans[i]` is the number of `1`s in the binary representation of `i`.

---

#### Example 1:

> Input: n = 2  
Output: [0,1,1]

#### Example 2:

> Input: n = 5  
Output: [0,1,1,2,1,2]

---

#### Constraints:

* `0 <= n <= 10^5`

---

#### Follow up:

Can you solve it in `O(n)` time without using any built-in function?
